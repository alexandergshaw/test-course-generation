# Personal Productivity Dashboard (Python Productivity Hub)

Semester-long Python course project using **Next.js App Router** + **Tailwind CSS**, designed for deployment on **Vercel**.

## Repository structure
- `/assignment0` onboarding
- `/assignment1` through `/assignment16` weekly work
- `/components` shared UI components
- `/app` Next.js app pages and API routes
- `vercel.json` deployment configuration

## Course schedule and assessment weeks
- Weeks 1-3: Basic Python (calculator + logic)
- Week 4: `review4` fundamentals review
- Week 5: `exam1` fundamentals assessment
- Weeks 6-8: Loops, functions, data structures
- Week 9: `review9` loops/functions/data review
- Week 10: `exam2` loops/functions/data assessment
- Weeks 11-14: File I/O, OOP, advanced features
- Week 15: `review15` advanced review
- Week 16: `exam3` comprehensive final

## Dynamic unlocking model
The dashboard reads assignment completion from backend checks and unlocks UI cards when assignment tests pass.
